## Codebase Patterns
- Use electron-vite for building Electron + Svelte apps
- TypeScript configs: tsconfig.node.json for main/preload, tsconfig.web.json for renderer
- Main process code in src/main/, preload in src/preload/, renderer in src/renderer/
- Run `npm run typecheck` to verify all TypeScript code
- Svelte 5 uses `mount()` instead of `new App()` pattern
- IPC pattern: Use `ipcMain.handle('channel', handler)` in main, `ipcRenderer.invoke('channel', args)` in preload
- Expose APIs via contextBridge.exposeInMainWorld('api', { ... }) in preload
- TypeScript types for window.api go in src/renderer/types/api.d.ts
- Svelte stores go in src/renderer/stores/
- Svelte 5 components use `$props()` for props: `let { propName }: Props = $props()`
- Components go in src/renderer/components/
- Git commands use execFile (promisified) from child_process in gitService.ts
- IPC error handling: All handlers wrapped in try-catch, return { error: true, message, handlerName } on error
- Use isIpcError() type guard from src/renderer/utils/ipcError.ts to check for IPC errors in renderer
