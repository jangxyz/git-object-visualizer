## Codebase Patterns
- CSS 변수는 App.svelte의 `.app.dark` 및 `.app.light` 클래스에 정의됨
- 테마 변경은 `theme` store를 통해 관리 (stores/theme.ts)
- D3.js 그래프 색상은 `getComputedStyle()`로 CSS 변수를 읽어서 적용
- 컴포넌트 스타일은 하드코딩 대신 `var(--variable-name)` 형식 사용
- 토스트 알림은 `toastStore`를 통해 관리 (stores/toast.ts)
- Git 명령어 실행에는 타임아웃 적용 (10초, gitService.ts의 execGitWithTimeout)
- 에러 처리 시 inline 에러와 토스트 알림 둘 다 표시하는 것이 좋음
