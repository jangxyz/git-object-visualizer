# PRD: Git Object Visualizer (Git 객체 시각화 도구)

## 소개

Git Object Visualizer는 Git의 내부 객체 구조(blob, tree, commit, tag)를 시각적으로 탐색할 수 있는 데스크톱 애플리케이션입니다. 사용자가 실제 저장소의 Git 객체들이 어떻게 구성되고 연결되어 있는지 직관적으로 이해할 수 있도록 돕고, 커밋에 따른 객체 변화를 추적하여 Git의 작동 원리를 학습할 수 있게 합니다.

**기술 스택**: Electron + Svelte

## 목표

- 사용자가 Git 객체(blob, tree, commit, tag) 간의 관계를 노드-엣지 그래프로 시각적으로 파악할 수 있다
- 커밋 히스토리에 따른 객체 변화를 타임라인으로 추적할 수 있다
- 파일/폴더 선택 시 해당 항목의 Git 객체 구조를 즉시 확인할 수 있다
- 각 시각화 요소에 대응하는 Git CLI 명령어를 제시하여 CLI 학습을 지원한다
- Git 입문자와 중급 개발자 모두에게 유용한 교육 도구를 제공한다

## 사용자 스토리

### US-001: 로컬 Git 저장소 열기
**설명:** 사용자로서, 로컬에 있는 Git 저장소를 선택하여 열 수 있어야 한다.

**인수 조건:**
- [ ] 폴더 선택 다이얼로그를 통해 디렉토리를 선택할 수 있다
- [ ] 선택한 디렉토리가 Git 저장소인지 검증한다 (.git 폴더 존재 확인)
- [ ] Git 저장소가 아닌 경우 명확한 에러 메시지를 표시한다
- [ ] 최근 열었던 저장소 목록을 표시한다 (최대 5개)
- [ ] Typecheck/lint 통과

### US-002: 객체 그래프 뷰 구현
**설명:** 사용자로서, 현재 HEAD 커밋의 Git 객체들을 노드-엣지 그래프로 볼 수 있어야 한다.

**인수 조건:**
- [ ] commit, tree, blob 객체를 서로 다른 색상/아이콘으로 구분하여 노드로 표시한다
- [ ] 객체 간의 참조 관계를 엣지(화살표)로 연결한다
- [ ] 각 노드에 객체 ID(SHA)의 앞 7자리를 표시한다
- [ ] 노드 클릭 시 해당 객체의 상세 정보를 사이드 패널에 표시한다
- [ ] 그래프를 드래그하여 이동하고 줌인/줌아웃할 수 있다
- [ ] Typecheck/lint 통과

### US-003: 객체 상세 정보 패널
**설명:** 사용자로서, 선택한 객체의 상세 정보를 확인할 수 있어야 한다.

**인수 조건:**
- [ ] 객체 타입(commit/tree/blob/tag)을 명확히 표시한다
- [ ] 전체 SHA 해시를 표시한다
- [ ] blob의 경우 파일 내용을 (일부) 미리보기로 표시한다
- [ ] tree의 경우 포함된 항목 목록을 표시한다
- [ ] commit의 경우 author, committer, message, parent 정보를 표시한다
- [ ] 해당 객체를 조회하는 Git CLI 명령어를 복사 버튼과 함께 표시한다
- [ ] Typecheck/lint 통과

### US-004: 파일 탐색기 뷰 구현
**설명:** 사용자로서, 저장소의 파일/폴더 구조를 탐색하고 선택한 항목의 Git 객체를 확인할 수 있어야 한다.

**인수 조건:**
- [ ] 현재 HEAD 기준의 파일/폴더 트리를 표시한다
- [ ] 폴더 클릭 시 하위 항목을 펼치거나 접을 수 있다
- [ ] 파일/폴더 선택 시 해당 객체(blob/tree)가 그래프 뷰에서 하이라이트된다
- [ ] 파일/폴더 선택 시 상세 정보 패널이 업데이트된다
- [ ] Typecheck/lint 통과

### US-005: 커밋 타임라인 뷰 구현
**설명:** 사용자로서, 커밋 히스토리를 타임라인으로 보고 특정 커밋을 선택하여 해당 시점의 객체를 탐색할 수 있어야 한다.

**인수 조건:**
- [ ] 최근 커밋들을 시간순으로 리스트 또는 타임라인 형태로 표시한다
- [ ] 각 커밋에 대해 SHA(앞 7자리), 메시지, 작성자, 날짜를 표시한다
- [ ] 커밋 선택 시 해당 커밋 기준으로 객체 그래프가 업데이트된다
- [ ] 현재 선택된 커밋이 시각적으로 구분된다
- [ ] Typecheck/lint 통과

### US-006: 통합 레이아웃 구성
**설명:** 사용자로서, 객체 그래프, 파일 탐색기, 타임라인을 한 화면에서 함께 볼 수 있어야 한다.

**인수 조건:**
- [ ] 화면을 3개 영역으로 분할한다: 좌측(파일 탐색기), 중앙(객체 그래프), 우측/하단(타임라인)
- [ ] 영역 간 크기를 드래그하여 조절할 수 있다
- [ ] 상세 정보 패널은 우측 사이드바 또는 모달로 표시한다
- [ ] 반응형으로 창 크기에 따라 레이아웃이 적절히 조정된다
- [ ] Typecheck/lint 통과

### US-007: Git CLI 명령어 학습 지원
**설명:** 사용자로서, 현재 보고 있는 시각화에 해당하는 Git CLI 명령어를 확인하고 복사할 수 있어야 한다.

**인수 조건:**
- [ ] 각 객체 조회 시 관련 명령어를 표시한다 (예: `git cat-file -p <sha>`)
- [ ] 커밋 히스토리 조회 명령어를 표시한다 (예: `git log --oneline`)
- [ ] 명령어 옆에 복사 버튼이 있어 클릭 시 클립보드에 복사된다
- [ ] 복사 완료 시 시각적 피드백을 제공한다 (예: 툴팁 "복사됨!")
- [ ] 명령어에 대한 간단한 설명을 툴팁으로 제공한다
- [ ] Typecheck/lint 통과

### US-008: Electron 앱 기본 설정
**설명:** 개발자로서, Electron + Svelte 프로젝트의 기본 구조를 설정해야 한다.

**인수 조건:**
- [ ] Electron + Svelte 보일러플레이트 프로젝트를 구성한다
- [ ] 개발 모드(hot reload)와 프로덕션 빌드가 동작한다
- [ ] IPC 통신 구조를 설정한다 (renderer ↔ main process)
- [ ] Git 명령어 실행을 위한 main process 핸들러를 구성한다
- [ ] TypeScript를 사용한다
- [ ] Typecheck/lint 통과

## 기능 요구사항

- FR-1: 시스템은 로컬 Git 저장소 경로를 입력받아 유효성을 검증할 수 있어야 한다
- FR-2: 시스템은 `git cat-file`, `git ls-tree`, `git log` 등의 명령어를 실행하여 객체 정보를 조회할 수 있어야 한다
- FR-3: 시스템은 commit → tree → blob 관계를 파싱하여 그래프 데이터 구조로 변환할 수 있어야 한다
- FR-4: 시스템은 노드-엣지 그래프를 인터랙티브하게 렌더링할 수 있어야 한다
- FR-5: 시스템은 파일 시스템 트리 구조를 표시하고 탐색할 수 있어야 한다
- FR-6: 시스템은 커밋 히스토리를 조회하고 타임라인으로 표시할 수 있어야 한다
- FR-7: 시스템은 사용자가 선택한 커밋 기준으로 객체 그래프를 재구성할 수 있어야 한다
- FR-8: 시스템은 Git CLI 명령어를 클립보드에 복사하는 기능을 제공해야 한다

## 비목표 (범위 제외)

- 원격 저장소(GitHub, GitLab 등) 직접 연결 및 조회
- Git 명령어 실행 기능 (읽기 전용, 저장소 변경 없음)
- Packfile/Delta 압축 등 저수준 저장소 최적화 시각화
- 브랜치 병합, 리베이스 등 복잡한 Git 작업 시각화
- 대용량 저장소 (10,000+ 커밋) 최적화
- 다국어 지원 (한국어 UI만 제공)
- 인터랙티브 튜토리얼/가이드 모드

## 디자인 고려사항

### UI/UX 요구사항
- 다크 테마를 기본으로 하되, 밝은 테마 옵션 제공
- 객체 타입별 색상 코드:
  - Commit: 파란색 계열
  - Tree: 초록색 계열
  - Blob: 노란색/주황색 계열
  - Tag: 보라색 계열
- 그래프 노드는 충분히 크게 하여 클릭하기 쉽게
- 명령어 복사 버튼은 아이콘(📋)으로 간결하게 표시

### 참고할 기존 도구
- GitKraken, SourceTree의 커밋 그래프 UI
- VS Code의 파일 탐색기 구조

## 기술 고려사항

### 의존성
- Electron: 데스크톱 앱 프레임워크
- Svelte: UI 프레임워크
- D3.js 또는 vis.js: 그래프 시각화
- simple-git 또는 child_process: Git 명령어 실행

### 보안 고려사항
- 저장소 경로는 사용자가 명시적으로 선택한 것만 접근
- 읽기 전용 Git 명령어만 실행 (write 명령어 차단)
- contextIsolation, nodeIntegration 설정 적절히 구성

## 성공 지표

- 사용자가 저장소를 열고 객체 그래프를 3초 이내에 확인할 수 있다
- 커밋 선택 후 그래프 업데이트가 1초 이내에 완료된다
- CLI 명령어 복사 기능이 1클릭으로 동작한다
- Git 입문자가 commit → tree → blob 관계를 시각적으로 이해할 수 있다
